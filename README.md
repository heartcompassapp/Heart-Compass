# HeartCompass

HeartCompass is a structured 90-day educational program for people navigating lipid results, prescriptions, and follow-up care between diagnosis and recheck.

## Development

This repository is a Next.js application.

### Prerequisites

- Node.js 22+
- npm 10+

### Setup

```bash
npm ci
```

### Commands

| Command | Description |
| --- | --- |
| `npm run dev` | Start the development server on port 3000 |
| `npm run build` | Create a production build |
| `npm run start` | Run the production server |
| `npm run lint` | Run ESLint |
| `npm run typecheck` | Run TypeScript checks |

### Cloud Agents

Cloud Agent environment configuration lives in `.cursor/environment.json`.
